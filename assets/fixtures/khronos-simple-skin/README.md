# Khronos SimpleSkin

External interoperability fixture with trailing whitespace normalized, no data changes. Primary
source:
[glTF-Sample-Assets / SimpleSkin](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/SimpleSkin),
author Marco Hutter (2017), model content CC0 1.0 Universal. The original license is in
`LICENSE.md`; that metadata file is CC-BY-4.0 and is kept with attribution to
KhronosGroup/glTF-Sample-Assets.

It contains a strip of eight triangles with two bones, blended weights and a 5.5 s LINEAR clip.
The importer must read its rig with its external buffers and interleaved accessors, in addition to
the assets generated by Mirai; the clip is not imported.
